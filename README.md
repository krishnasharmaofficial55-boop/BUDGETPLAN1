# BudgetPlan beta (no login, on-device storage)
Static site: deploy this folder to Vercel/Netlify/Cloudflare Pages (HTTPS automatic). No backend, keys or env vars.
Data lives in each user's browser localStorage (private, but lost if browser data is cleared; no sync across devices). CSV export is the backup.
